# Preference Keys

Stored with the Tauri store plugin in `preferences.json` in the app data folder, through [`packages/frontend/src/lib/preferences.ts`](../../packages/frontend/src/lib/preferences.ts). All keys are defined in [`packages/frontend/src/lib/storage-keys.ts`](../../packages/frontend/src/lib/storage-keys.ts).

| Key                                 | Value                                                                                              | Default                         | Owner                                                                                                                                                |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nookly:sidebar-collapsed`          | `"1"` collapsed, `"0"` expanded                                                                    | expanded                        | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:right-sidebar-collapsed`    | `"1"` collapsed, `"0"` expanded                                                                    | expanded                        | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:right-sidebar-width`        | width in pixels, clamped to 184 to 480                                                             | `288`                           | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:active-space`               | id of the last active Space, removed when none                                                     | none                            | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:expanded-spaces`            | JSON array of expanded Space ids; several can be expanded at once                                  | `[]`                            | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:recents`                    | JSON array of `{ entityId, spaceId, openedAt }`, max 5                                             | `[]`                            | [`packages/frontend/src/lib/store/nav.ts`](../../packages/frontend/src/lib/store/nav.ts)                                                             |
| `nookly:cli-install-card-dismissed` | `"1"` once dismissed                                                                               | shown                           | [`packages/frontend/src/components/sidebar/cli-install-card.tsx`](../../packages/frontend/src/components/sidebar/cli-install-card.tsx)               |
| `nookly:theme`                      | `"light"`, `"dark"` or `"system"`                                                                  | `"system"`                      | [`packages/frontend/src/lib/theme.ts`](../../packages/frontend/src/lib/theme.ts)                                                                     |
| `nookly:file-viewer-theme`          | `"light"`, `"dark"` or `"system"` (`"system"` follows the app's own theme)                         | `"light"`                       | [`packages/frontend/src/lib/file-viewer-theme.ts`](../../packages/frontend/src/lib/file-viewer-theme.ts)                                             |
| `nookly:notes-sort`                 | `"<column>:<direction>"`, column `key`, `edited` or `title`, direction `asc` or `desc`             | `"edited:desc"`                 | [`packages/frontend/src/features/notes/NotesListView.tsx`](../../packages/frontend/src/features/notes/NotesListView.tsx)                             |
| `nookly:jots-sort`                  | `"<column>:<direction>"`, column `key`, `edited` or `title`, direction `asc` or `desc`             | `"edited:desc"`                 | [`packages/frontend/src/features/notes/JotsListView.tsx`](../../packages/frontend/src/features/notes/JotsListView.tsx)                               |
| `nookly:jots-preset`                | id of the last picked preset: `unrefined`, `refined`, `week` or `all`                              | `"unrefined"`                   | [`packages/frontend/src/features/notes/JotsListView.tsx`](../../packages/frontend/src/features/notes/JotsListView.tsx)                               |
| `nookly:tasks-display`              | JSON `{ tab, layout, grouping, subGrouping, ordering, showEmpty, properties }`                     | board grouped by status         | [`packages/frontend/src/features/tasks/task-model.ts`](../../packages/frontend/src/features/tasks/task-model.ts)                                     |
| `nookly:assignments-display`        | JSON `{ layout, grouping, subGrouping, showEmpty }`                                                | list grouped by deadline        | [`packages/frontend/src/features/assignments/assignment-model.ts`](../../packages/frontend/src/features/assignments/assignment-model.ts)             |
| `nookly:files-display`              | JSON `{ layout, grouping, ordering }`                                                              | grid, no grouping, newest first | [`packages/frontend/src/features/files/file-model.ts`](../../packages/frontend/src/features/files/file-model.ts)                                     |
| `nookly:bookmarks-display`          | JSON `{ layout, grouping, ordering, showPreviews, showDescriptions }`                              | grid, no grouping, newest first | [`packages/frontend/src/features/bookmarks/bookmark-model.ts`](../../packages/frontend/src/features/bookmarks/bookmark-model.ts)                     |
| `nookly:related-tab`                | id of the tab last picked under an Assignment or Exam: `tasks`, `notes`, `decks` or `study-blocks` | `"tasks"`                       | [`packages/frontend/src/features/relationships/RelatedItemsSection.tsx`](../../packages/frontend/src/features/relationships/RelatedItemsSection.tsx) |
| `nookly:timezone`                   | IANA zone like `"Europe/Berlin"`, or `"system"`                                                    | `"system"`                      | [`packages/frontend/src/lib/datetime.ts`](../../packages/frontend/src/lib/datetime.ts)                                                               |
| `nookly:date-format`                | `"american"`, `"european"` or `"timezone"`                                                         | `"timezone"`                    | [`packages/frontend/src/lib/datetime.ts`](../../packages/frontend/src/lib/datetime.ts)                                                               |

| `nookly:sessions-view`              | `"day"`, `"workweek"`, `"week"` or `"month"`                                                       | `"week"`                        | [`packages/frontend/src/features/sessions/calendar/calendar-model.ts`](../../packages/frontend/src/features/sessions/calendar/calendar-model.ts)     |
