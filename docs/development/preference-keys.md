# Preference Keys

Stored with the Tauri store plugin in `preferences.json` in the app data folder, through [`src/lib/preferences.ts`](../../src/lib/preferences.ts). All keys are defined in [`src/lib/storage-keys.ts`](../../src/lib/storage-keys.ts).

| Key                                 | Value                                                                                              | Default                         | Owner                                                                                                            |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `nookly:sidebar-collapsed`          | `"1"` collapsed, `"0"` expanded                                                                    | expanded                        | [`src/lib/store/nav.ts`](../../src/lib/store/nav.ts)                                                             |
| `nookly:right-sidebar-collapsed`    | `"1"` collapsed, `"0"` expanded                                                                    | expanded                        | [`src/lib/store/nav.ts`](../../src/lib/store/nav.ts)                                                             |
| `nookly:right-sidebar-width`        | width in pixels, clamped to 184 to 480                                                             | `288`                           | [`src/lib/store/nav.ts`](../../src/lib/store/nav.ts)                                                             |
| `nookly:active-space`               | id of the last active Space, removed when none                                                     | none                            | [`src/lib/store/nav.ts`](../../src/lib/store/nav.ts)                                                             |
| `nookly:recents`                    | JSON array of `{ entityId, spaceId, openedAt }`, max 5                                             | `[]`                            | [`src/lib/store/nav.ts`](../../src/lib/store/nav.ts)                                                             |
| `nookly:cli-install-card-dismissed` | `"1"` once dismissed                                                                               | shown                           | [`src/components/sidebar/cli-install-card.tsx`](../../src/components/sidebar/cli-install-card.tsx)               |
| `nookly:theme`                      | `"light"`, `"dark"` or `"system"`                                                                  | `"system"`                      | [`src/lib/theme.ts`](../../src/lib/theme.ts)                                                                     |
| `nookly:notes-sort`                 | `"<column>:<direction>"`, column `key`, `edited` or `title`, direction `asc` or `desc`             | `"edited:desc"`                 | [`src/features/notes/NotesListView.tsx`](../../src/features/notes/NotesListView.tsx)                             |
| `nookly:jots-sort`                  | `"<column>:<direction>"`, column `key`, `edited` or `title`, direction `asc` or `desc`             | `"edited:desc"`                 | [`src/features/notes/JotsListView.tsx`](../../src/features/notes/JotsListView.tsx)                               |
| `nookly:jots-preset`                | id of the last picked preset: `unrefined`, `refined`, `week` or `all`                              | `"unrefined"`                   | [`src/features/notes/JotsListView.tsx`](../../src/features/notes/JotsListView.tsx)                               |
| `nookly:tasks-display`              | JSON `{ tab, layout, grouping, subGrouping, ordering, showEmpty, properties }`                     | board grouped by status         | [`src/features/tasks/task-model.ts`](../../src/features/tasks/task-model.ts)                                     |
| `nookly:assignments-display`        | JSON `{ layout, grouping, subGrouping, showEmpty }`                                                | list grouped by deadline        | [`src/features/assignments/assignment-model.ts`](../../src/features/assignments/assignment-model.ts)             |
| `nookly:files-display`              | JSON `{ layout, grouping, ordering }`                                                              | grid, no grouping, newest first | [`src/features/files/file-model.ts`](../../src/features/files/file-model.ts)                                     |
| `nookly:bookmarks-display`          | JSON `{ layout, grouping, ordering, showPreviews, showDescriptions }`                              | grid, no grouping, newest first | [`src/features/bookmarks/bookmark-model.ts`](../../src/features/bookmarks/bookmark-model.ts)                     |
| `nookly:related-tab`                | id of the tab last picked under an Assignment or Exam: `tasks`, `notes`, `decks` or `study-blocks` | `"tasks"`                       | [`src/features/relationships/RelatedItemsSection.tsx`](../../src/features/relationships/RelatedItemsSection.tsx) |
| `nookly:timezone`                   | IANA zone like `"Europe/Berlin"`, or `"system"`                                                    | `"system"`                      | [`src/lib/datetime.ts`](../../src/lib/datetime.ts)                                                               |
| `nookly:date-format`                | `"american"`, `"european"` or `"timezone"`                                                         | `"timezone"`                    | [`src/lib/datetime.ts`](../../src/lib/datetime.ts)                                                               |
| `nookly:time-format`                | `"american"`, `"european"` or `"timezone"`                                                         | `"timezone"`                    | [`src/lib/datetime.ts`](../../src/lib/datetime.ts)                                                               |
| `nookly:sessions-view`              | `"day"`, `"workweek"`, `"week"` or `"month"`                                                       | `"week"`                        | [`src/features/sessions/calendar/calendar-model.ts`](../../src/features/sessions/calendar/calendar-model.ts)     |
